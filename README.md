## MiniMax H3是什么？核心能力一览

MiniMax H3 由 **MiniMax** 推出，发布时间 **2026年7月31日**，属于视频生成类模型。全模态生成模型：文本、图像、视频、声音统一理解，直接输出带原生双声道的 15 秒 2K 视频。

- **全模态统一**：H3 不是“文生视频”单点能力，而是统一理解文本、图像、视频、声音四种上下文的通用生成模型。
- **原生双声道**：音频和画面在同一次生成中产出，口型、环境声、音效天然对齐，省掉后期配音与对轨。
- **参考控制**：最多 9 张图 + 3 段视频 + 3 段音频做参考，角色一致性、运镜风格、音色的可控性接近导演级。
- **商用能力**：官方称具备商用级多场景内容生成能力，适合广告、电商、短剧、社媒的批量出片。

## MiniMax H3 中转站接入教程（3 分钟）

### 第 1 步：拿地址与 Key

1. 注册并登录 [https://api.catrouter.net](https://api.catrouter.net)；
2. 在控制台创建 API 令牌，得到一把通用 Key；
3. 记下 BaseURL：`https://api.catrouter.net/v1`。

### 第 2 步：OpenAI 兼容方式调用

```bash
curl https://api.catrouter.net/v1/chat/completions \
  -H "Authorization: Bearer sk-你的中转Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "minimax-h3",
    "messages": [{"role": "user", "content": "你好，介绍一下你自己"}]
  }'
```

```python
from openai import OpenAI

client = OpenAI(api_key="sk-你的中转Key", base_url="https://api.catrouter.net/v1")

resp = client.chat.completions.create(
    model="minimax-h3",
    messages=[{"role": "user", "content": "写一段产品介绍"}],
    stream=True,
)
for chunk in resp:
    print(chunk.choices[0].delta.content or "", end="")
```

### 第 3 步：视频生成调用

```python
# 视频类接口按平台任务式协议提交，先建任务再轮询结果
task = client.videos.create(
    model="minimax-h3",
    prompt="竖屏 9:16，产品特写推镜，暖光，背景音轻柔",
    duration=5,
)
print(task.id)  # 轮询任务状态获取成片地址
```

### 第 4 步：验证与压测

- 用同一段提示词分别跑中转与直连，对比延迟与输出一致性；
- 连续跑 20–50 次，观察失败率与 P95 延迟；
